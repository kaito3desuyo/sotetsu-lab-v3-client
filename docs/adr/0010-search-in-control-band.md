# ADR-0010: 検索カードをトップ専用にし、操作を操作帯にまとめる

- **日時**: 2026-10-22
- **Agent**: claude-opus-5-5
- **ステータス**: 採用済み
- **ブランチ**: feat/control-band-search
- **関連**: ADR-0001（操作帯 `app-control-band`）

---

## 背景

- 検索カード（時刻表を検索する・運用情報を検索する）は各ページの一番下にあり、長い表を見ていると条件を替えるのに最下部まで行く必要があった。
- 操作帯（ADR-0001）が全ページに載り、ページの条件の多くは帯で替えられるようになっていたため、カードの中身の大半は帯と重複していた。

## 決定

- トップ以外のページから検索カードを消す。帯に無い中身だけを帯に足す。リンク（リアルタイム／過去の運用情報）はサイドナビにあるので足さない。
- 前後の駅・運用へ送るボタン（`app-step-nav`）と今日のダイヤのボタン（`app-today-calendar-button`）を足す。送りは帯を開いたときの名前付きボタンだけにし、要約の行には置かない（2026-10-22 ユーザー指示。要約の文が狭くなる）。
- リアルタイムの投稿カードを、右下の固定ボタン＋投稿ダイアログに替える。フォームは `app-operation-post-form` に切り出してトップのカードと共用する。

## 影響

- 下部のカードぶん各ページが短くなる。カードの導線（自己リンクの除外など）の掟は不要になる。
- 帯が背の高いページ（運用行路図）ができる。scroll 型の帯なので、スクロールすれば要約の行（40px）だけ残る。全線時刻表は列車ダイヤグラムと同じ manual 型の帯で、ページがスクロールしない画面いっぱいの箱に置く（2026-10-22 ユーザー指示）。
