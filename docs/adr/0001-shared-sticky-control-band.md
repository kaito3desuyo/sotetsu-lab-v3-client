# ADR-0001: ページ上端の操作帯を、貼り付く共通部品 `app-control-band` にまとめる

- **日時**: 2026-10-06
- **Agent**: claude-opus-5-5
- **ステータス**: 採用済み
- **ブランチ**: feature/sticky-control-band（PR #231）

---

## 背景

- 操作系があるページ（全線時刻表・駅別時刻表・運用行路図・リアルタイム運用情報・過去の運用情報・運用表・列車位置情報・列車ダイヤグラム）は、どれも上端に絞り込みなどの操作帯を持つ。
- 下へスクロールすると操作帯が見えなくなり、絞り込みを変えるには一番上まで戻る必要があった。何で絞り込んでいるのかも見えなくなっていた。
- 操作帯の中身（チップ・選択欄・時刻の入力など）はページごとに違う。一方で「貼り付く・畳む・開く・絞り込み中を示す」という振る舞いは、どのページでもそろえたい。

## 決定

### 1. 共通部品 `app-control-band`（`src/app/shared/control-band/`）に振る舞いをまとめる

- 中身はページが `<ng-content>` で差し込む。部品は中身を知らない。
- 部品が持つもの: 貼り付き（`position: sticky`）、要約の行（要約の文・［解除］・「開く／畳む」）、絞り込み中の縦線、開く・畳むの動き、閉じる操作（幕・Esc・Tab で外へ出る・スクロール）。
- ページが渡すもの: 要約の文（`summary`）、絞り込み中か（`filterActive`）、［解除］を出すか（`clearable`）、`clear` の受け取り。
- 要約の文を組み立てる処理は、ページごとに `utils/*-summary.util.ts` の純粋な関数に切り出してテストする。文の形がページごとに違うので、共通の部品には入れない。

### 2. 操作部の DOM は 1 組だけ持つ

- 要約の行は初めから帯の一番下に出しておく。スクロールではその上の操作部だけがヘッダーの下に潜り、要約の行（40px）が残る。
- 開くときも操作部を作り直さず、同じ要素の `top` を変えてページに重ねる。選択の状態が二重にならず、各ページの部品もそのまま動く。

### 3. 2 つの形を `collapse` で選ぶ

- `scroll`（既定）: 貼り付き、どこからでも重ねて開ける。
- `manual`（列車ダイヤグラム）: 固定も重ねもせず、畳むと図が伸びる。畳んだ状態はページのストアに保存する。

### 4. ページとの約束

- 帯がある間は `<html>` に `--control-band-offset: 40px` を入れる。ページの中で貼り付く物や、画面の高さに合わせた箱は、この分を差し引く。
- 帯（またはそれを置く部品）を `div` などで包まない。sticky は親要素の中でしか止まらないからだ。帯を自分の中に置く部品は、host を `display: contents` にする。
- 重なりの順は、読み込み中のバー `tw-z-[60]` ＞ 帯 `tw-z-50` ＞ 幕 `tw-z-40` ＞ ページの中の貼り付く物（最大 `tw-z-30`）。

細かな数値・振る舞い・経緯は、設計書 `docs/superpowers/specs/2026-10-06-sticky-control-band-design.md` と `docs/design.md` の「操作帯は貼り付き、どこからでも開ける」に書いた。

## 結果

- 8 ページの操作帯が同じ振る舞いになった。新しいページも、この部品に中身と要約を渡すだけで同じになる。
- 振る舞いの直し（文言・動き・閉じる操作など）は、部品 1 か所を直せば全ページに効く。
- 代わりに、ページ側は上の「約束」（変数を差し引く・包まない・重なりの順）を守る必要がある。運用行路図では、帯を `div` で包んでいたために貼り付かない不具合が出た。

## 検討した代案

- **ページごとに作る**: 中身に合わせやすいが、動きや閉じ方がそろわない。
- **細帯を別の部品にし、操作部をもう 1 組出す**: テンプレートと選択の状態が二重になる。
- **スクロール量に合わせて少しずつ畳み、操作部に覆いを被せて消す**: 実装したが、薄いまま押せる・影が急に付く・要約の行が二重になる、と細かい直しが続いたのでやめた（ユーザー判断 2026-10-06）。
