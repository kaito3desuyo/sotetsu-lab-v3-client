# 操作帯の貼り付きと折りたたみ 設計

2026-10-06

## 目的

利用者の要望は次の 2 つだ。

1. 「絞り込みを、スクロールしても上に貼り付けたままにしてほしい（PC・スマホ）」
2. 絞り込みが効いていることに気付けるようにしてほしい。2026-10-06、リアルタイム運用情報で「列車が出ない」と報告があったが、絞り込みが有効になっていただけだった。

ユーザーの指示は次のとおり。

-   「要約帯はいいアイデアだが、画面上のどの位置にいても折りたたまれた状態を開いて絞り込みを変更できるように」
-   範囲は「操作系があるページはすべて」。
-   列車ダイヤグラムにも「折りたたみはできるようにしたほうがいい」。畳んだ状態は「覚えておかせる」。

## 対象

| ページ               | 帯の今の作り                                                                |
| -------------------- | --------------------------------------------------------------------------- |
| 全線時刻表           | `app-control-band`（`timetable-all-line-route-filter` の中）                |
| 駅別時刻表           | `app-control-band`                                                          |
| 運用行路図           | `app-control-band`（`operation-route-diagram-route-filter` の中）           |
| リアルタイム運用情報 | `app-control-band`                                                          |
| 過去の運用情報       | `app-control-band`                                                          |
| 運用表               | `app-control-band`                                                          |
| 列車位置情報         | 自前の帯（`app-train-location-controller` の外側）                          |
| 列車ダイヤグラム     | 自前の帯（`app-train-diagram-controller` の外側）。ページはスクロールしない |

対象外：投稿カード、ダッシュボード、時刻表の入力。

## 合格の条件

-   8 ページとも、390px と 1440px の幅で、どのスクロール位置からでも、スクロールせずに絞り込みを変えられる。列車ダイヤグラムは、畳んだ状態から開いて変えられる。
-   貼り付いた帯が、今ある中身（貼り付く見出し・駅名の行など）を隠さない。
-   絞り込みが効いているのに、利用者が気付けないという状態が起きない。

## 方式

共通の帯 `app-control-band` そのものに、貼り付きと折りたたみを持たせる（3 案のうち A を採用）。

-   操作部の DOM は 1 つだけにする。細帯や展開にしても作り直さず、同じ要素を CSS で固定し、畳んだり広げたりする。選択の状態が二重にならず、各ページの部品もそのまま動く。
-   不採用にした案：
    -   B：細帯を別の部品にし、開いたら操作部をもう 1 組出す。テンプレートが二重になり、片方だけ直し忘れる心配がある。
    -   C：ページごとに自前で作る。同じことを 8 回書くことになり、動きもそろわない。

## 共通の帯の状態

### `collapse="scroll"`（初めの値。7 ページ）

帯は `position: sticky` で、要約の行を初めから帯の一番下に出しておき、スクロールではその上の操作部だけがヘッダーの下に潜る（ユーザー判断 2026-10-06「最初から要約を表示した上でスクロールしたら畳む、の方がより実装がシンプルなのでは？」→「そうしよう」）。

-   帯は上から 操作部・要約の行（40px）の順。要約の行はページの一番上でも出ている。何件に絞れているかが一番上でも見える。
-   帯の `top` は「ヘッダーの高さ（48px、md 以上は 64px）＋ 40px ＋ 帯の下の罫線 1px − 帯の高さ」。帯はページと一緒に上へ流れ、要約の行だけが残った所でヘッダーの下に止まる。ページの流れから抜けないので中身は跳ねない。
-   操作部は薄くしない・覆わない。そのままヘッダーの下に滑り込んで隠れる。要約の行の濃さも変えない。
-   以前の作り（スクロール量から畳み具合を出し、操作部に白い覆いを被せて消しながら要約を濃くする）はやめた。薄いまま押せる・影が急に付く・要約の行が二重になる、と細かい直しが続いたからだ。その前の作り（帯が隠れたら `position: fixed` の細帯に替える）は、細帯が突然現れたように見えたのでやめた。
-   影は付けない。開いて重ねている間も、白い帯と灰色のページ地の差と下の罫線で分ける（ユーザー指摘 2026-10-06「開いた時にだけ影がつくのはおかしい」。その前の「止まったときだけ影」も、急に付いて見えて直していた）。
-   一番上でも畳める（ユーザー指示 2026-10-06「一番上にいる状態の時もたためてほしい」）。操作部の一部でもヘッダーより下に見えている間は、要約の行のボタンが「▲ 畳む」になる。押すとその場で操作部を隠し、帯は要約の行だけになってヘッダーのすぐ下に止まる。
-   畳んだまま一番上（`scrollY` が 0）で「▼ 開く」と、その場で広げる。スクロールした後の「▼ 開く」は、操作部を要約の行の下に落として重ねる（帯の高さを変えない。変えると、ページの中身が伸びた分だけ下へ跳ねる）。閉じると畳んだ状態に戻る。
-   開く・畳むは動かす（ユーザー指示 2026-10-06「開く/畳む動きはアニメーションしてほしい」）。操作部は外側を `display: grid` にして `grid-template-rows` を 0fr⇄1fr で 200ms 遷移させ、高さを伸び縮みさせる（中身は `min-h-0` と `overflow-hidden`）。隠れている間は `inert` で押せなくする。止まった帯の「開く」は host の `top` を遷移させ、帯ごとヘッダーの下から滑り降ろす。その場で畳む・広げる動きの間（250ms）は操作部をページの流れに置いたままにし、終わってから要約の行の下に落とす形へ切り替える。`prefers-reduced-motion` では遷移しない。
-   操作部が見えているかは IntersectionObserver で見る（ヘッダーの高さ ＋ 1px を `rootMargin` で差し引く。操作部の下の端が縁にちょうど接しただけで「見えている」と出ないように）。スクロールのたびの計算はしない。
-   要約の行は、要約の文・［解除］・「▼ 開く」。「開く」で帯の `top` をヘッダーの高さにし、帯の全部を降ろしてページに重ねる。要約の行はそのまま帯の一番下にあり、ボタンが「▲ 畳む」になる（要約の行は 1 つだけ）。操作部の高さの上限は「画面 − ヘッダー − 40px」で、はみ出す分は中でスクロールする。
-   展開は、次のときに閉じる。
    -   「▲ 畳む」を押す
    -   パネルの外を押す（透明な幕を敷く。ヘッダーは押せるまま残す）
    -   Esc（閉じたら「開く／畳む」のボタンにフォーカスを戻す。mat-select の選択肢を閉じる Esc のように、ほかの部品が処理した Esc（`defaultPrevented`）では閉じない）
    -   Tab でフォーカスが帯の外へ出る（開いたまま幕の裏の本文にフォーカスが移らないように。mat-select の選択肢など cdk の overlay へ移るのは帯の中と同じに扱う）
    -   利用者がページをスクロールする
-   チップや選択欄を操作しても閉じない。
-   「利用者がスクロールした」は scroll イベントでは見ない。幕の上での `wheel`・`touchmove` と、帯の外で押したスクロールするキー（PageUp・PageDown・Home・End・Space・上下の矢印）で判定する。
    -   絞り込むとページが短くなり、ブラウザがスクロール位置を詰める。これも scroll イベントとして飛んでくるので、scroll イベントで閉じると、チップを押した瞬間に閉じてしまう。
-   帯を自分の中に置いている部品（全線時刻表・運用行路図の路線の絞り込み）は、host を `display: contents` にする。sticky は親要素の中でしか止まらないからだ。ページの側でも、帯（またはその部品）を `div` などで包まない（運用行路図で包んでいて貼り付かなかった。2026-10-06）。

### `collapse="manual"`（列車ダイヤグラム）

-   要約の行は `scroll` と同じく初めから帯の一番下に出し、そこに「▲ 畳む」を置く。押すと操作部を隠し、要約の行だけの 40px の 1 行になる。操作部の右に「畳む」の列を取ると、スマホでチップや選択欄が狭くなったのでやめた（2026-10-06）。
-   畳んだ 1 行は、固定も重ねもしない。今の帯の場所にそのまま収まる。浮いた高さのぶん、図のカード（`tw-flex-1`）が伸びる。
-   「▼ 開く」を押すと、帯を元の場所に押し広げて戻す。重ねないのは、図の上の方が隠れたまま戻らないからだ。
-   `--control-band-offset` は使わない。このページの図の大きさは、`main` の固定の高さと `flex-1` だけで決まる。

### 細帯・畳んだ 1 行の中身（両方で同じ）

-   要約の文は 1 行にし、収まらない分は「…」で切る。
-   右端に「▼ 開く」と「▲ 畳む」の切り替えボタンを置く。文言はこの 2 つだけで、重ねた操作部を閉じるときも「畳む」（ユーザー指摘 2026-10-06「開く、畳む、閉じるになってる」）。要約の行は 1 つだけ。
-   絞り込み中は、左端にアクセント色の縦線を出す。
-   ［解除］は、絞り込み中で、かつ `clearable` のページだけに出す。
-   要約・▼・［解除］の縦の中心をそろえる。
-   高さは 40px に固定する。4px の倍数で、中身によって高さが変わらない。

## 部品の入力と出力

```ts
summary = input(''); // 細帯・畳んだ 1 行に出す文
filterActive = input(false); // 左の色の線と［解除］
clearable = input(false); // ［解除］を出すページか
collapse = input<'scroll' | 'manual'>('scroll');
collapsed = model(false); // manual のときの開閉。ページが保存する
clear = output<void>(); // ［解除］を押した
```

列車位置情報・列車ダイヤグラムは、図を全幅で見せるため外周の余白を持たない（design.md「余白の掟」2）。共通の帯は、外周の余白を負のマージンで打ち消す前提で作ってある。この 2 ページでは打ち消しを外す必要がある。入力を足すか、ページ側の class で上書きするかは、実装のときに実物を見て決める。

## CSS 変数 `--control-band-offset`

-   `scroll` の帯があるページでは、`<html>` に `--control-band-offset: 40px` をずっと入れておく。要約の行はいつも 40px 残るので、ほかの物が貼り付く高さまでスクロールしたときには、必ず帯が止まっている。部品が消えたとき（帯の無いページに移ったとき）は外す。
-   止まったかどうかは見ない。値が途中で変わらないので、箱の高さも途中で変わらない。
-   使う側は、どこも `var(--control-band-offset, 0px)` と、`0px` を初めの値にして書く。

| 場所                                                                 | 今                                                       | 直したあと                                                                            |
| -------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 駅別時刻表 `timetable-station.component.html` の貼り付く行           | `tw-top-12 md:tw-top-16`                                 | ヘッダーの高さ ＋ 変数                                                                |
| 駅別時刻表 `timetable-station-table.component.html` の貼り付く見出し | `tw-top-[114px] md:tw-top-[130px]`                       | 同じく ＋ 変数                                                                        |
| 全線時刻表・過去の運用情報・運用行路図の、画面の高さに合わせた箱     | `max-h-[calc(100dvh-80px)] md:max-h-[calc(100dvh-96px)]` | さらに − 変数                                                                         |
| 読み込み中のバー（ヘッダーのすぐ下に固定）                           | `tw-top-[48px] md:tw-top-[64px]`                         | 位置は変えない。z を `tw-z-[60]` にそろえ、細帯（`tw-z-50`）の上に 4px の線として出す |

-   時刻表の入力の箱も同じ形だが、帯が無いので値はいつも `0px` だ。触らない。
-   重なりの順は、上から ヘッダー（ページの外・`tw-z-30`）＞ 読み込み中のバー `tw-z-[60]` ＞ 細帯・パネル `tw-z-50` ＞ 透明な幕 `tw-z-40` ＞ ページの中の貼り付く物（最大 `tw-z-30`）。
    ページは `layout` の `tw-relative tw-z-0` の中にあるので、どの値もヘッダーとドロワーより下になる。

## ページごとのつなぎ方

| ページ               | collapse | 要約の例                                                            | 絞り込み中               | ［解除］               |
| -------------------- | -------- | ------------------------------------------------------------------- | ------------------------ | ---------------------- |
| リアルタイム運用情報 | scroll   | 「絞り込み中：東急・K群（目黒線） 36/120 運用」／「絞り込み：なし」 | 会社か運用群を選んでいる | ある（選択を空にする） |
| 運用表               | scroll   | 「2026/3/14改正 平日 絞り込み中：G群（東横線） 5/90 運用」          | 運用群を選んでいる       | ある                   |
| 過去の運用情報       | scroll   | 「10/6 から 7 日間 絞り込み中：東急」（日付と日数は検索欄の値）     | 会社を選んでいる         | ある                   |
| 運用行路図           | scroll   | 「路線：本線・厚木線・新横浜線」／「全路線」                        | 路線を絞っている         | なし                   |
| 全線時刻表           | scroll   | 「路線：相鉄の 4 路線」／「全路線」                                 | 路線を絞っている         | なし                   |
| 駅別時刻表           | scroll   | 「横浜 2026/3/14改正 平日 下り」                                    | なし                     | なし                   |
| 列車位置情報         | scroll   | 「本線 現在時刻（今日のダイヤ）」／「本線 8:00 指定 平日」          | なし                     | なし                   |
| 列車ダイヤグラム     | manual   | 「本線 平日 下り」                                                  | なし                     | なし                   |

-   絞り込みは「空＝全部」の掟に従う。何も選んでいなければ、絞り込み中ではない。
-   要約の文は、帯を置いているコンポーネントが `computed` で作る。値はどれも、もうそのコンポーネントが持っているシグナルから作れる。
-   文の形がページごとに違うので、共通の部品には入れない。文を組み立てる部分はページごとに純粋な関数として `utils/` に切り出し、テストする。
-   ダイヤの表記は「2026/3/14改正」にそろえる（design.md の掟）。
-   列車位置情報・列車ダイヤグラムは、自前の白帯を `app-control-band` に置き換える。中のコントローラーには手を入れない。

## 列車ダイヤグラムの畳んだ状態の保存

-   `TrainDiagramStore` の `StoreProps` に `controlCollapsed: boolean`（初めの値は `false`）を足す。
-   `persistState` で保存する。保存先は運用表・リアルタイムと同じ `localForage`、キーは `TrainDiagramStore`。
-   保存するのは `controlCollapsed` だけにする。

    -   このストアは今まで何も保存していない。全部保存すると、列車データ（数 MB）まで書くことになる。
    -   開いたときに前のダイヤや路線へ戻るようになり、動きが変わる。
    -   ライブラリには `excludeKeys` しか無いので、`source` で 1 項目だけ流す。

    ```ts
    const persist = persistState(store, {
        key: 'TrainDiagramStore',
        storage: localForage,
        source: (s) =>
            s.pipe(
                select((state) => state.controlCollapsed),
                map((controlCollapsed) => ({ controlCollapsed })),
            ),
    });
    ```

-   ストアから `persistInitialized$: persist.initialized$` を出す。
-   `TrainDiagramResolverService` に `mergeMap(() => TrainDiagramStore.persistInitialized$)` を足す。運用表・リアルタイム・ダッシュボード・時刻表の入力と同じ形だ。画面に移った時点で畳んだ状態が決まっているので、一瞬開いて見えることはない。

## 確かめ方

### jest（`npx jest --testPathPattern=…`、結果はファイルに出す）

-   共通の帯：
    -   帯の高さから `top` を決めること（ResizeObserver・matchMedia はテストで差し替える）
    -   空きの高さが残ること
    -   展開と閉じる条件。チップを押しても閉じないこと、ページが勝手に詰めた scroll では閉じないこと
    -   `--control-band-offset` を入れて戻すこと、部品が消えたら `0px` に戻すこと
    -   `manual` での畳む・開くと、`collapsed` の出入り
    -   ［解除］の出し分けと `clear` の発火
-   要約の文を作る関数：ページごとの spec。
-   `TrainDiagramStore`：`controlCollapsed` だけを保存すること。resolver：保存した値を読んでから解決すること。
-   変えたページの既存の spec を全部流す。

### 実物（Playwright・本番データ・390px と 1440px）

-   8 ページそれぞれで目で見る。下までスクロールした位置から細帯を開き、絞り込みを変えると結果がその場で変わること。パネルが閉じないこと。
-   実測で確かめる。
    -   細帯が、駅別時刻表の貼り付く見出し、箱の中の見出し、行路図の駅名の行を隠さないこと
    -   帯が止まる瞬間に、ページが跳ねないこと（scrollY と、先頭に見えている要素の位置で測る）
    -   細帯の要約・▼・［解除］の縦の中心がそろっていること
-   列車ダイヤグラム：畳むと図が伸びること。再読み込みしても畳んだまま出ること。
-   390px で、展開したパネルが画面に収まらないとき、パネルの中でスクロールして下まで届くこと。
