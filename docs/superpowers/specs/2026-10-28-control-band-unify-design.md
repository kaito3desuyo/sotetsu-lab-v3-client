# 操作帯の畳み方・貼り付き・保存をそろえる

- **日時**: 2026-10-28
- **ブランチ**: refactor/control-band-unify
- **関連**: `src/app/shared/control-band/control-band.component.ts`、docs/design.md「操作帯は貼り付き、どこからでも開ける」、ADR-0014（SSR の描き分け・`afterFirstRender`）

## なぜ

操作帯（`app-control-band`）の扱いがページで 2 通りある（ユーザー指示 2026-10-28「各ページのヘッダー下の白帯のたたみ状態の取り扱い統一したい」）。

- scroll 型（6 ページ）: スクロールすると操作部が隠れ、要約の行だけが貼り付く。畳んだ状態は保存しない。
- manual 型（列車ダイヤグラム・全線時刻表）: ボタンでだけ畳む。畳んだ状態は保存する。

高さ固定（`main` が `calc(100dvh-…)`）はやめない。外すと、横スクロールの箱の中の貼り付く見出しが壊れ、横スクロールバーがページの下端に行き、触ってスクロールするときにページと箱で取り合いになるため（2026-10-28 に説明し、ユーザーは「全部」そろえる方を選んだ）。

## 決めたこと（ユーザー判断 2026-10-28）

1. **畳み方は scroll 型に寄せる。**
2. **畳んだ状態はページごとに保存する。**
3. 高さ固定のページで、箱のスクロールで操作部が隠れた後に「開く」を押すと、**重ねて開く**（scroll 型と同じ）。箱の高さは変わらない。
4. 高さ固定のページで、スクロールで隠れた操作部は、**「開く」でだけ**出す。箱を一番上に戻しても、自動では出さない。

## 振る舞い

### 全ページ共通

- 帯は上から、操作部・要約の行（40px）の順。「畳む」「開く」のボタン、幕、Esc・Tab で閉じる動きは今のまま。
- 「畳む」で畳んだ状態（`collapsed`）を、各ページのストアの `withSettingsStorage` の `controlCollapsed` に保存する。キーはページごとに別。
  - スクロールで隠れた状態は保存しない。保存するのは、ボタンで畳んだ状態だけ。
- 保存した状態を戻すのは、最初の描画の後（`afterFirstRender`。ADR-0014）。SSR では開いた形で描く。今の 2 ページと同じ。

### ページがスクロールするページ（今の scroll 型）

- 今と同じ。要約の行が貼り付き、操作部はヘッダーの下に潜る。
- 違いは、`collapsed` をページのストアとつなぐことだけ。今は部品の中の model で、ページを離れると消える。

### 高さ固定のページ（列車ダイヤグラム・全線時刻表）

- ページ全体はスクロールしない。図・表の箱（以下「箱」）が縦横にスクロールする。
- **利用者が箱をスクロールしたら、操作部をその場で隠して要約の行だけにする。** 隠した分、箱が伸びる（grid の 0fr/1fr で 200ms で動く。今の畳む動きと同じ）。
  - 「利用者がスクロールした」とみなすのは、箱の中で起きた `wheel`・`touchmove`・スクロールのキー（PageUp・PageDown・Home・End・Space・↑↓）だけ。`scroll` イベントでは数えない。
  - プログラムで動かすスクロール（ダイヤグラムの「今」・時刻へ移る、表の向き替え）では隠れない。
  - 2 本指のピンチで拡大縮小しても隠れる（触って動かしたので）。
- スクロールで隠れたら、ボタンは「開く」。押すと、操作部を要約の行の下に**重ねて**開く（幕つき）。閉じると要約の行に戻る。
- スクロールで隠れた操作部は、ページを開き直すまで「開く」でしか出ない。
- 操作部が出ている間の「畳む」は、今の manual と同じ。その場で畳んで保存する。
- ボタンで畳んでいる間の「開く」は、その場で広げる。高さ固定のページは、いつも「一番上にいる」のと同じなので、scroll 型が一番上で広げるのと同じ動きにする。

## 作りの方針

- 部品の型は `collapse: 'page' | 'box'` に改める（`'scroll'`・`'manual'` は消す）。既定は `'page'`。
  - `'page'` は今の scroll 型そのまま。
  - `'box'` は高さ固定のページ用。sticky にしない。`--control-band-offset` を入れない（ページがスクロールしないので、貼り付く物の位置を下げる必要がない）。
- 箱には属性 `data-control-band-scroll` を付ける。部品は `document` で `wheel`・`touchmove`（passive）・`keydown` を聞き、`target.closest('[data-control-band-scroll]')` に当たったときだけ数える。箱の要素を入力で渡さない（全線は箱が子の部品の奥にあるため）。
- `'box'` でスクロールで隠れた状態は、部品の中の signal（保存しない）。
- 重ねて開くのは、今の scroll 型の「畳んだ後に開く」と同じ置き方（要約の行の下に `absolute` で落とす）を使う。

## やらないこと

- 高さ固定をやめること。
- zoneless・他の帯の見た目を変えること。
- 保存の形式（`withSettingsStorage`）を変えること。

## 確かめ方

- 部品の spec（`control-band.component.spec.ts`）に `'box'` の振る舞いを足す: 箱の wheel・touchmove・キーで隠れる／箱の外では隠れない／scroll イベントだけでは隠れない／隠れた後の「開く」は重ねる・閉じると隠れたまま／ボタンで畳む・広げるはその場。
- 8 ページで、畳んでから再読み込みすると畳んだまま開くこと。
- 実データの画面で、412px と 1440px の両方を見る: ダイヤグラムと全線で、箱をスクロールしたら帯が要約の行になり箱が伸びる・「今」では隠れない・重ねて開いた選択欄が選べる。scroll 型のページは前と同じ。
