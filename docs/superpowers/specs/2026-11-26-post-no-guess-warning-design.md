# 目撃の投稿フォームで推測の投稿を禁じる

## ねらい

見ていない編成を、順送りなどから当たりを付けて投稿する人が続いている。投稿フォームで、推測の投稿は禁止だと知らせ、最初の投稿の前に、見た編成だけを投稿すると確かめさせる。決まりを知らずに推測で投稿する人を止めるのが目的だ。知っていて推測で投稿する人は、投稿の管理（M18 の削除や BAN）で扱う。

## 作り方の候補

- 警告を出すだけ：手間は増えないが、そのうち読まれなくなる
- 警告を出し、投稿のたびにチェックを入れさせる：よく投稿する人ほど手間が増え、読まずに入れる癖が付く
- 警告はいつも出し、チェックは端末ごとに最初の 1 回だけ入れさせる：ユーザーがこれを選んだ

## 決めたこと

- 置き場所は `shared/operation-post-card/operation-post-form.component.html` の、目撃時刻の欄と「投稿する」ボタンの間。投稿カードを置くどのページにも出る
- 警告の文（いつも出す。アイコンは `error_outline`）：
  「実際に目撃した編成のみを投稿してください。順送りなどから推測した編成の投稿は禁止しています。繰り返される場合は、投稿権限を剥奪することがあります。」
  最後の文はユーザーの文で、推敲で変えない。前の 2 文は `docs/style-profile.md` の硬さにそろえた
- チェック（`mat-checkbox`）の文：「目撃した編成のみを投稿します」
- チェックが入るまで、「投稿する」は他の欄が空のときと同じく `ariaDisabled` で出す。押したら送らず、チェックの下に「チェックを入れてください」と出す
- チェックを入れたことは `OperationPostCardStore` の新しい欄に持ち、`withSettingsStorage` の `fields` に足して端末に覚えさせる。外したら覚えも外す
- 覚えるのは端末ごと。アカウントごとにすると api と DB に手が入るので、しない
- ログインしていない人と BAN 済みの人にはフォームが出ないので、警告も出ない

## 作る人に任せること

- 警告の色と余白。隣の部品と同じ Tailwind の書き方にそろえ、手元の画面で実物を見て決める
- spec の分け方。少なくとも「チェックが無いと送らない」「入れると端末に覚え、次に開いたときは入った状態で出る」を確かめる
