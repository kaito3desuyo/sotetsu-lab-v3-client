# 列車位置情報（train-location）骨格の作り直し — 設計

- 日付: 2026-09-26
- ブランチ: `feature/redesign-2026-07`
- 対象: `src/app/pages/train-location/**`（と `shared/train-position.util.ts` の export 追加）

## 目的

このページで**一番先に分かるべきことは「ある駅に次に来る列車」**（ユーザー判断 2026-09-26）。
路線全体の図は残し、駅を選ぶとその駅を起点に上り・下りの「次に来る列車」を出す。

現状（モック 09 準拠の縦 1 本線）の問題:

1. 主要駅の判定が壊れていて全駅が大きい丸になる（通過駅の時刻 `null` を「時刻あり」と数える・種別名「各停（SO）」が `'各停'` と一致しない）
2. 「🚈 n本停車中」の絵文字が豆腐になり、ボタンの字が Arial
3. PC 1440px で幅 672px の中央寄せ。画面の半分しか使わない
4. 駅の間隔が一律で 18 駅 1,695px。駅名が丸の下にあり線が切れて見える
5. 免責文が 2 か所。プログレスバーが紺。カードに影（面の掟に反する）

## 決定事項（ユーザー判断）

| 項目             | 決定                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------ |
| 主な用途         | ある駅に次に来る列車                                                                 |
| 図と駅           | 図は残し、駅を選ぶとその駅の欄を出す                                                 |
| 駅の選び方       | 図の駅を押す。URL に `station_id`。前回の駅を路線ごとに覚える                        |
| 通過・回送       | 含めて「通過」の印を付ける（通過時刻は推定なので「頃」）                             |
| PC の骨格        | 案A: 縦の図（左）＋駅の欄（右・sticky）。案B（横の図）・案C（駅の横に重ねる）は不採用 |
| 乗換駅           | 他線へのリンクを図と駅の欄の両方に出す。押すと同じ駅を選んだ状態で開く                |

比較に使ったモック（実データ・土休日 09:59・本線・二俣川）: `.playwright-mcp/tl-mock-{A,B,C}.png`（git 管理外）。

### PC（`lg` 以上）

- 本体は 2 列の grid: 図 640px ＋ 駅の欄（残り幅）。駅の欄は `position: sticky` で図のスクロールに付いてくる
- canvas 系なので外周 gutter の掟（余白の掟 2）に従う。図の上下の chrome は横 12px の inset

### スマホ（`lg` 未満）

- 状態の行 → 駅の欄（畳める。開閉は localStorage に保存）→ 縦の図 の順に縦積み

### 図

- **駅**: 線の上に載る丸い札（`button`）。主要駅は太字。選択中は紺の塗り＋橙（accent）の輪。押すと選ぶ
- **乗換**: 札の横に他線の路線チップ（小）。リンク先は `['/train-location', { route_id, station_id }]`
- **駅の間**: 在線の本数で高さを伸ばす（空は 30px）。18 駅で約 1,300px。進捗位置の衝突回避は既存の `resolveBetweenRowLayout` を使う
- **カード**: 中身は今のまま（種別チップ・行先・運用・列番・▲▼/停車中・会社・編成）。影をやめて `--color-rule-2` の細い縁
- **同じ駅に複数停車**: 「n本停車中」の吹き出し（CDK オーバーレイ）をやめ、全カードを縦に並べる（情報を隠さない）

### 駅の欄

- 見出し: 駅名（大）＋乗換の路線チップ＋「に次に来る列車（ダイヤ通り）」
- 上り・下りの 2 段。方面の名前は駅軸の両端の駅から作る（例 本線は「横浜方面」「海老名方面」）
- 1 行: あと何分（「まもなく」は 1 分未満）・時刻・種別チップ・行先 行・列番・運用・いまどこか
  - 通過: 時刻に「頃」、行に「通過」の印
  - 回送: 種別チップが回送（灰）。行先はそのまま
  - その駅が終点の列車: 「当駅止まり」
  - いまどこか: 在線中は「いま 瀬谷→三ツ境」「いま 鶴ヶ峰に停車中」、まだ出ていない列車は「海老名 10:02 発」
- 各方向 6 本まで。あと 2 分以内の行は淡い accent の地
- 駅が未選択: 「図の駅名を押して駅を選ぶ」とだけ出す
- 各方向で該当が 0 本（終電後など）: 「この先の列車はありません」

## データと部品

### 新しい純関数 `utils/build-station-arrivals.util.ts`

```ts
buildStationArrivals(input: {
    tripBlocks: readonly TripBlockDetailsDto[];
    axisStationIds: ReadonlySet<string>;
    stationId: string;
    at: Date;
    positions: readonly TrainPosition[];
    cardsById: ReadonlyMap<string, TrainLocationCard>;
    stationNameById: ReadonlyMap<string, string>;
    limit: number; // 6
}): { inbound: StationArrival[]; outbound: StationArrival[] }
```

- 時刻の解釈は `shared/train-position.util.ts` と同一規則にするため、同ファイルの `resolveArrival` /
  `resolveDeparture`（null の扱い・1 始まりの days・`getRailwayDate`）を **export して再利用**する（中身は変えない。ダッシュボードも使うため）
- 停車: 着時刻（無ければ発時刻）。発時刻が `at` 以降なら停車中でも出す
- 通過: 前後の停車点（発着のどちらかがある times）の時刻を stopSequence の比で按分。`isPassing: true`
- 対象: 選んだ駅の時刻（または推定時刻）が `at` 以降の trip。上り・下りは `tripDirection`（0 = 上り）
- 行先・運用・編成・種別色は `cardsById`（既存 `buildTrainLocationCards`）から引く。無い trip は trip 自身から組み立てる
- いまどこか: `positions` から。無ければ始発駅（trip の最初の停車点）と発時刻

### 部品

| 部品                              | 変更                                                                                   |
| --------------------------------- | -------------------------------------------------------------------------------------- |
| `train-location-station-panel`    | 新規。駅の欄（見出し・乗換チップ・上り/下りの行・空状態・スマホの開閉）                |
| `train-location-line`             | 駅を丸い札の `button` に。乗換チップを札の横へ。複数停車の CDK オーバーレイを削除。`stationSelect` を出す |
| `train-location-card`             | 影 → 細い縁                                                                            |

| `train-location-controller`       | 免責文を削除（ページ下端に 1 か所）                                                    |
| ページ本体                        | 状態の行・2 列 grid・`station_id` の扱い・プログレスバーを accent に                    |

### 状態

- `station_id` は URL の matrix param。無ければ localStorage（キー `train-location:station:<routeId>`）の値で補い `replaceUrl` で載せる
- 選んだ駅が駅軸に無い（路線を変えた等）ときは未選択として扱う
- スマホの駅の欄の開閉: localStorage `train-location:panel-open`
- localStorage はすべて try/catch。読めなくても未選択・開いた状態で動く
- ストア（`TrainLocationStore`）に `selectedStationId` を足す。永続化の方針は変えない

### 主要駅の判定の修正（`determine-major-stations.util.ts`）

- 発着の有無は `!= null` で判定
- 各停かどうかは種別名が「各停」で始まるか。回送（「回送」で始まる）も主要駅の根拠にしない
