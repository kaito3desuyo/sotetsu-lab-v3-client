# M30 投稿のしやすさ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 投稿フォームに「列車から選ぶ」・編成番号の候補・送る前の確認を足し、3 ページに投稿の入口を足し、どこから投稿したかを GA で測れるようにする。

**Architecture:** 列車の一覧は `shared/train-picker/`（純関数＋ストア＋部品）に置き、今日のダイヤの運行を `TripBlockService.findManyByCalendarId`＋`TRIP_BLOCK_TIMELINE_FIELDS`（列車位置情報・ダイヤグラム・トップと取得結果のキャッシュを共有）で取る。api は変えない（2026-11-10 に本番の列車位置情報を Playwright で開いて実測: 平日ダイヤの上り 1.80MB・下り 1.82MB、gzip で各 207KB、取得 718〜907ms。キャッシュの無いページで初めて「列車から選ぶ」を開いたときに 1 秒前後待つだけなので、口は足さない）。送る前の確認と時刻の換算は `shared/operation-post-card/` の純関数にし、フォームはそれを呼ぶだけにする。入口は既存の `OperationPostDialogService.open()` に「開いた場所」を足して使う。

**Tech Stack:** Angular 22（standalone・OnPush・signal）、@ngrx/signals、Angular Material（mat-select・mat-autocomplete）、Tailwind（`tw-` 接頭辞）、date-fns、Jest。

**Spec:** `docs/superpowers/specs/2026-11-10-m30-post-ease-design.md`

## Global Constraints

- api の検証の境目（未来の時刻・始発の 30 分前）は緩めない。api のコードは触らない。
- 運用番号の欄は手で打つまま。「列車から選ぶ」は足すだけ。
- 入口から開くとき時刻は埋めない（運用番号だけ・時刻は「現在時刻」のまま）。
- 編成番号の候補に「その運用に充当していると推測される編成」を出さない。
- 情報は削らない（design.md・情報削減禁止）。列車の行は「時刻・種別・列車番号・行先・運用番号」。
- 休車（100）は列車の一覧に出さない。手で打つ「100」は送る前の確認で止めない。
- 4 時の境目（04:00〜翌 03:59 を 1 営業日）。
- 全部を 1 本の PR（ブランチ `feature/m30-post-ease`）。
- ロック済みページ（列車ダイヤグラム・列車位置情報・駅別時刻表）は design.md の節を先に書き足してから反映する。
- コンポーネントは OnPush・standalone・`inject()`・private は `#`。Tailwind は `tw-` 接頭辞。border は `tw-border-solid` を付ける。`ngClass` でなく `[class]`。余白は 4px 単位。
- 文言（そのまま使う）:
    - 未来の時刻: `未来の時刻は指定できません`（api と同じ）
    - 運用番号が無い: `指定された運用番号の運用情報が見つかりません`（api と同じ）
    - 編成の注意: `今日の編成に無い番号です（車両番号ならそのまま送れます）`
    - ボタン: `列車から選ぶ`
- コミットは Conventional Commits＋絵文字（例 `feat: :sparkles: …`）・署名付き（サンドボックス外）。jest は `npx jest --testPathPatterns=<spec>`、整形は prettier をファイル単位。

## Review Focus

1. **4 時をまたぐ時刻**: 3:50 に開くと、前後 10 分の一覧は前日の営業日の 27:40〜28:00（days=2 の 03:40〜04:00）を出し、4:05 に開くと当日の 3:55〜4:15 になる。→ Task 1 のテスト。
2. **今日の一覧がまだ無い・取れていない**: `TodaysOperationListState`・`TodaysFormationListState` が空のとき、送る前の確認は何も止めない・注意も出さない（全員の投稿を止めない）。→ Task 2 のテスト。
3. **車両番号での入力**: 「10701」の編成に属する車両「10101」を打っても止めない（注意だけ）。→ Task 2 のテスト。
4. **列車から選んだ後に手で書き換え**: 選んだ後に運用番号を手で打ち直したら、GA の「列車から選んだ」は 0 に戻る。→ Task 4 のテスト。
5. **昔のダイヤを見ているとき**: ダイヤグラム・列車位置情報で今日以外のダイヤを見ているときは入口を出さない（その運用番号が今日に無いことがある）。→ Task 6・7 のテスト。
